# Babyway

Public marketing site for [Babyway](https://thelittledaysapp.com), the shared baby tracker for the whole family.

This repository is only the website (home, support, and privacy). The app itself lives in a separate repo and should keep its own GitHub Pages origin, so families who already installed it are not disrupted.

Custom domain: `thelittledaysapp.com` (stays live after the Babyway rename until a new domain is bought; CNAME unchanged).
